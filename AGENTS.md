# AGENTS.md

Facts about this repository for coding and triage agents. Procedures live in
`.claude/skills/`; hard limits are enforced by configuration (see the end).

## Build and test

| what | command |
|---|---|
| build | `go build` |
| unit tests | `go test ./...` |
| integration tests | `go run cmd/integration_test/main.go cli` |
| triage scripts tests | `python3 -m pytest tests/` (Python 3, stdlib only) |
| compile the agent workflow | `gh aw compile` (commit the `.lock.yml`) |

Go version: see `go.mod`. Dependencies are vendored in `vendor/`.

## Structure

| path | content |
|---|---|
| `pkg/gui` | TUI: controllers, contexts, views, keybindings |
| `pkg/commands/git_commands` | wrappers that build and run git commands |
| `pkg/config` | lazygit's own `config.yml` (user config) schema/defaults |
| `pkg/i18n` | UI strings and translations |
| `pkg/integration` | integration test framework and tests |
| `docs/` | user docs (`Config.md`, keybindings, ...) |
| `.claude/skills/lazygit-triage/` | issue-triage skill, label catalog, scripts |
| `.github/workflows/issue-triage.md` | gh-aw triage agent (source of `.lock.yml`) |
| `evals/` | measured need (`need/`) and golden evaluation (`golden/`) |

This repo is a sandbox: lazygit source is a snapshot of upstream
`jesseduffield/lazygit` at `eb351dc` (see `SNAPSHOT.md`).

## Conventions

- Issues use upstream's templates in `.github/ISSUE_TEMPLATE/`; they apply
  `bug`, `enhancement` or `discussion` automatically.
- Upstream asks contributors to discuss a change in an issue before a PR,
  and closes PRs it suspects were generated by a coding agent
  (`CONTRIBUTING.md`, "A note about AI"). The triage agent therefore never
  proposes code or PRs.
- Label meanings, with positive and negative examples:
  `.claude/skills/lazygit-triage/labels.json`.

## Forbidden changes

- Editing `.github/`, `.claude/`, `AGENTS.md`, `go.mod`, `go.sum`.
- Closing, locking, assigning, or editing issues; merging or pushing.

These are **enforced**, not just documented here:
workflow `permissions` are read-only, the only write paths are the
`add-labels` / `add-comment` / `noop` safe outputs
(`.github/workflows/issue-triage.md`), and `.github/CODEOWNERS` requires
the owner's review for the protected paths.
